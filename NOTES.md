# NOTES — Эпичные схватки боевых магов (цифровой порт)

Читать в начале каждой новой сессии вместо всего проекта.

## Цель
Telegram Mini App по настольной игре Epic Spell Wars of the Battle Wizards: Duel at Mt. Skullzfyre: 2–6 игроков, друзья по ссылке-приглашению и боты, в первую очередь вертикальный телефон. Ассеты — только для игры с друзьями.

## Правила работы (как в D:\max-apocalypse\PROMPT.md)
- Пользователь не программист: отвечать коротко и просто, по-русски. Перед шагом — сказать, что делаю.
- Работа по фазам; после каждой фазы отчёт и ждать «ок». Ничего не угадывать — спрашивать.
- Тестирует сам (с телефона в Telegram / `npm.cmd run dev`); браузер и Playwright сам не запускать, хватает `npm.cmd run build`.
- Картинки карт не открывать без нужды; большие JSON — только маленьким node-скриптом со сводкой. Субагентов не использовать.
- npm через `npm.cmd` (PowerShell блокирует npm.ps1).
- Публичный репозиторий — только после явного «да» пользователя. Пароли/логины вводит сам.
- В конце фазы обновлять этот файл.

## Стек (берём образец из D:\max-apocalypse, его не трогаем)
- React + TypeScript + Vite, `base` под GitHub Pages; пути к ассетам через `import.meta.env.BASE_URL`.
- `src/telegram.ts` (Mini App, приглашения `startapp`), `src/net/*` + `firestore.rules` (хост прогоняет действия, остальные — очередь), `.github/workflows/deploy.yml`.
- Движок: чистая `reduce(state, action)`, детерминированный RNG в состоянии; состояние — в один документ Firestore.
- Боты: MCTS в Web Worker (`src/ai/*`).
- Ограничения Telegram WebView: без Path2D(svg), color-mix, CSS.escape, background-attachment: fixed; без двойных анимаций.

## Фаза 3 — движок (src/game/) — сделана, ждёт «ок»
- `types.ts` — состояние (`GameState`, ~2 КБ на 6 игроков) и действия: `submit` (карты + место: source/quality/delivery, `goLast` — сбросить Ранец), `choose` (ответ на вопрос), `nextGame`.
- `core.ts` — RNG в состоянии, колоды (перемешивание сброса, когда кончились), урон/лечение (макс. 25), смерть (рука/сокровища в сброс, карта дохлого, конец игры при ≤1 живом), соседи (левый враг = следующий живой по часовой, т.е. по возрастанию id), знаки, могучий бросок со всеми сокровищами-модификаторами, вопросы игрокам.
- `effects.ts` — эффекты всех 63 карт (по индексу), «Шальная магия» (`replaceWild`), добавление карт к заклинанию.
- `engine.ts` — `create(players, seed, medalsToWin=2)`, `reduce`, `tryReduce`, `waitingFor`. Фазы: start → build → resolve → (раунд) … → gameover → nextGame → … → tournament.
- Вопросы: шаг, которому нужен ответ, останавливается (`pending` с вариантами); ответ перезапускает шаг с начала с накопленными ответами (`pending.base` — JSON до шага). Эффекты карт пишутся обычным кодом через `ask()`. Один вариант — без вопроса.
- `legal.ts` — все допустимые действия игрока (для ботов и проверок).
- Проверки: `npm.cmd test` (scripts/scenarios.ts — очерёдность, Нетерпеливый, кубики со знаком сокровища, Шальная магия, Шерочка, вопросы, смерть/медаль/дохлые/следующая игра, турнир, Ранец) и `npm.cmd run sim` (случайные турниры 2–6 игроков: сохранность всех карт, жизни, зависания). 200 турниров (673 игры) — без ошибок.

- `ui/simpleBot.ts` — временный простой бот (большие заклинания одной школы, бьёт самых хилых, остальное наугад). В фазе 5 — MCTS.

- Телефон: долгое нажатие (~0,3 с) на карту в руке — крупная копия, пока держишь (`peek` в useBuilder); не отпуская, палец влево-вправо — листать руку (карта под пальцем, `data-card`), вверх на 60px — тащить увеличенную карту; копия стоит по центру пальца, низ — на 18px выше пальца (палец не закрывает текст), едет за пальцем; быстрое движение без долгого нажатия — перетаскивание; короткое — просмотр. - Рука: веер помещается в ширину (поля 12px, крайние карты ниже, наклон до 4°); при сборе заклинания на арене — ячейки в форме карт.

## Подбор игроков (по просьбе: быстрая игра, «сервера», закрытые комнаты)

## Музыка
- Плеер `ui/music.ts`: плейлист `public/assets/music/playlist.json` ([{file, title}]), играет на экране боя, по кругу; 🎵 в шапке — включить/выключить, ⏮/⏭, громкость (localStorage `esw-music`). Нет плейлиста — нет кнопки. Запуск звука — после первого касания (требование браузеров).

Музыка на сайте будет в открытом доступе.
- Свои песни игрока: в окне 🎵 «＋ Добавить песни с устройства» — файлы хранятся только на устройстве (IndexedDB `esw-music`), в список, нажатие — играть, ✕ — убрать. Кнопка 🎵 видна всегда.

## Решения по спорным местам (можно поменять)
- Сокровища «считается картой со знаком» добавляют знак (кубики, уникальные знаки), но не карту (очерёдность, «Бомжья коровка»).
- Колдун погиб в свой ход — остаток заклинания не применяется. Игра кончается сразу, как жив ≤1; если погибли все — медаль ходящему.
- «Труселя»: +2 к могучему броску одним кубиком и к своим одиночным броскам, где важен «результат» (Жгун, Котострофический, Хокер); где «сколько выпало» — без +2.
- Дискотечный/Брадострел: текст чужой карты, но знак и тип — копирующей (для кубиков, Кольца, Колотушки). «Шерочка» действует только на настоящие приходы.
- «Шальная магия», добавленная в заклинание эффектом (Рубин, Качковый, Подвязки), — игрок выбирает, какой тип она заменит.
- Ядрёный синтез: 1 урон соседям жертвы, в том числе самому колдуну. Двуличный может выбрать и себя. Качковый: при ничьей считаешься самым хилым.
- Шлакошангри-ла: +1 кубик ко всем могучим броскам в свой первый ход следующей игры.
- Загнивающий сбрасывает карту с места наворота (даже если там закрытая «Шальная магия»).
- Карта дохлого, взятая живым (Мерлин), тоже применяется в следующей игре.
- Ранец «ходить последним» — галочка при выкладывании заклинания. «Протонная ловушка» — карта-«Шальная магия» в заклинании (id −1).
- «50 оттенков свинофермы» — та же карта = то же название; можно сбрасывать несколько.
- Ничьи по инициативе — кубик, запоминается до конца раунда.
